## ✨ المميزات الرئيسية (Key Features)

1. **ثنائي اللغة (Bilingual Support - AR / EN)**:
   - التبديل الفوري بنقرة واحدة بين العربية (RTL) والإنجليزية (LTR).
   - حفظ تلقائي للغة المفضلة للزائر في المتصفح.

2. **مولد رمز الاستجابة السريعة (Dynamic QR Code)**:
   - رمز QR عالي الدقة يفتح المنيو فوراً عند مسحه بكاميرا أي هاتف (iPhone / Android).
   - زر مدمج لتحميل رمز الـ QR بدقة عالية لطباعته على ستيكرات الطاولات والمنشورات.

3. **خرائط جوجل لجميع الفروع (Google Maps Navigation)**:
   - ربط مباشر لكل فرع من الفروع الـ 12 بالخرائط عبر زر مخصص، يفتح تطبيق Google Maps مباشرة مع الاتجاهات.
   - فلترة الفروع حسب المحافظة (سوهاج، القاهرة، الإسكندرية، دمياط، الجيزة، المنوفية، القليوبية).

4. **اتصال مباشر بنقرة واحدة (Direct Phone Dialing)**:
   - جميع أرقام الفروع والخط الساخن قابلة للضغط والاتصال الفوري مثل بورتفوليو المواقع الاحترافية.
   - الخط الساخن: `01130355151` - `01055400546`.

5. **سلة طلبات ذكية عبر واتساب (WhatsApp Order System)**:
   - اختيار نوع الخبز (فينو / بلدي) وحجم الوجبة (صغير / وسط / كبير / بالكيلو).
   - حساب إجمالي الفاتورة آلياً وتجهيز رسالة واتساب منظمة ومفصلة بضغطة زر.

6. **عرض المنشور الأصلي (Original Flyer Viewer)**:
   - إمكانية استعراض النسخة الورقية المطبوعة بدقة عالية داخل نافذة منبثقة تفاعلية.
